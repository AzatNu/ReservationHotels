Для запуска веб-страницы необходимо: Клонировать себе весь репозиторий, далее перейти в директорию "Frontend" открыть терминал и установить все зависимости командой "npm i", далее запустить режим разработки командой "npm start".
Потом необходимо проделать тоже самое с директорий "Backend". Установить зависимости "npm i", запустить "npm run server". При успешном запуске серверной части в консоль выйдет сообщение "База данных подключена на порту 3005".
